# claude-personal

A personal workspace repository for projects developed with Claude Code.
Each project lives in its own top-level folder so the repo can grow without
things getting tangled.

## Projects

| Project | Folder | What it is |
|---------|--------|------------|
| **AeroCert Partners — Airline AOC Consultancy** | [`airline-aoc-consultancy/`](airline-aoc-consultancy/) | A business-creation plan for a specialist consultancy that helps operators obtain and maintain **UK CAA** and **EASA** Air Operator Certificates (AOCs), plus a slide deck and reusable delivery templates. |

## Airline AOC Consultancy — at a glance

- **Business plan** — a ten-part plan in [`airline-aoc-consultancy/business-plan/`](airline-aoc-consultancy/business-plan/): executive summary, market analysis, services, a UK/EASA regulatory primer, delivery model, org & staffing, financials, go-to-market, risk, and a 0–18 month roadmap.
- **Slide deck** — `airline-aoc-consultancy/AeroCert-AOC-Business-Plan.pptx`, a 14-slide presentation of the plan.
- **Templates** — client-facing delivery assets in [`airline-aoc-consultancy/templates/`](airline-aoc-consultancy/templates/).

See [`airline-aoc-consultancy/README.md`](airline-aoc-consultancy/README.md) for the full project map.

## Note

Content here is planning and reference material, not professional advice.
Figures and the working name *AeroCert Partners* are illustrative placeholders,
and regulatory details should always be verified against current UK CAA / EASA
sources before being relied upon.
