# Template — AOC Application Project Plan

> Reusable skeleton for a Tier 2 certification programme. Copy per client,
> fill the brackets, and delete guidance notes. Aligns to the five-phase
> certification process (see business plan Section 3). **Not legal advice** —
> validate every requirement against current UK CAA / EASA / NAA source
> material for the specific engagement.

## Engagement header

- **Client / applicant:** [legal entity]
- **Jurisdiction(s):** [ ] UK CAA  [ ] EASA — state: __________  [ ] Both
- **Operation type:** [passenger CAT / cargo / ACMI / business jet / rotary / special ops]
- **Fleet / types:** [type(s) and count]
- **Special approvals sought:** [PBN / LVO / ETOPS-EDTO / RVSM / DG / HEMS / HHO / offshore / ACMI …]
- **Target certificate date:** [date]
- **Programme lead (AeroCert):** [name]
- **Client Accountable Manager:** [name]

## Phase 1 — Pre-application

- [ ] Eligibility & credibility confirmed (funding, structure, intent)
- [ ] Jurisdiction decision finalised and rationale documented
- [ ] Initial enquiry / application-intent lodged with the authority
- [ ] High-level scope and operations specification drafted
- [ ] Programme plan, RACI, and cadence agreed with client

## Phase 2 — Formal application

- [ ] Formal application and supporting schedule submitted
- [ ] Proposed nominated/responsible persons identified
- [ ] Compliance / gap plan submitted
- [ ] Operating Licence (economic) workstream initiated with client's lawyers
- [ ] Airworthiness / CAMO / Part-145 arrangements confirmed or contracted

## Phase 3 — Document evaluation

- [ ] Management system & SMS documentation complete
- [ ] Operations Manual **Part A** (General/Basic)
- [ ] Operations Manual **Part B** (Aircraft operating — per type)
- [ ] Operations Manual **Part C** (Route/area & aerodrome)
- [ ] Operations Manual **Part D** (Training)
- [ ] Compliance Monitoring documentation
- [ ] **MEL** developed from MMEL
- [ ] **CAME** / continuing-airworthiness exposition (via CAMO partner)
- [ ] Training & checking documentation
- [ ] Compliance matrix mapping every requirement → manual section → evidence
- [ ] Authority findings log opened; responses tracked to closure

## Phase 4 — Demonstration & inspection

- [ ] Nominated/responsible persons accepted by the authority
- [ ] Mock audit / internal readiness review passed
- [ ] Facilities, records, and systems inspection ready
- [ ] Demonstration / proving activity (incl. proving flights where required)
- [ ] Outstanding findings closed

## Phase 5 — Certification

- [ ] AOC and operations specifications issued
- [ ] Operating Licence granted (where applicable)
- [ ] Scope, limitations, and conditions confirmed with client
- [ ] Handover pack delivered (docs, compliance register, obligations briefing)
- [ ] **Tier 3 retained-compliance** engagement proposed and agreed

## Cross-cutting tracks (run throughout)

- **Authority liaison log** — every contact, request, and commitment recorded.
- **Findings/action register** — owner and due date on every item.
- **Risks & assumptions** — kept live; variations raised for out-of-scope work.
- **Weekly client cadence** — status, critical path, decisions needed.

## Key dependencies OUTSIDE our control (flag early and often)

- Authority review and inspection timelines.
- Client recruitment and acceptance of postholders.
- Aircraft delivery, registration, and airworthiness.
- Client funding milestones and Operating Licence financial evidence.
