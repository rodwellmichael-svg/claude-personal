# Template — Client Engagement & Scoping Checklist

> Use at enquiry and scoping to qualify the client, size the programme, and set
> up a clean engagement. Copy per prospect.

## 1. Qualification (decide: pursue / decline)

- [ ] **Who** is the applicant? Legal entity, ownership, control.
- [ ] **Funding** — is the operation credibly capitalised through certification
      *and* early operations?
- [ ] **Intent & timeline** — realistic, or driven by an undeliverable date?
- [ ] **Decision-makers** — is there an identified Accountable Manager?
- [ ] **Red flags** — under-capitalisation, unrealistic timeline, unwillingness
      to pay a deposit, prior failed attempt with unaddressed causes.

> If qualification fails, decline politely. A bad engagement costs more than it
> earns (see business plan Section 8).

## 2. Scoping (the five axes)

- [ ] **Jurisdiction(s):** UK / EASA (which state) / both
- [ ] **Operation type:** passenger CAT / cargo / ACMI / business jet / rotary /
      special ops
- [ ] **Fleet:** number of types (drives OM Part B, training, airworthiness)
- [ ] **Special approvals:** PBN / LVO / ETOPS-EDTO / RVSM / DG / HEMS / HHO /
      offshore / ACMI
- [ ] **Client maturity:** greenfield vs existing systems to reuse

## 3. Current-state gap review

- [ ] Existing management system / SMS?
- [ ] Any existing manuals or documentation to build from?
- [ ] Postholders / responsible persons identified? Acceptable?
- [ ] Airworthiness arrangements (CAMO / Part-145) in place or contracted?
- [ ] Operating Licence / economic authorisation status and ownership tests?
- [ ] Facilities, IT, and record-keeping readiness?

## 4. Commercials

- [ ] Recommended tier(s): Tier 1 / Tier 2 / Tier 3 (+ specialist modules)
- [ ] Effort estimate from the five axes → fee and milestones
- [ ] Explicit **exclusions** stated (authority fees, legal, recruitment, CAMO)
- [ ] Assumptions and variation mechanism documented
- [ ] Deposit and milestone-billing schedule agreed
- [ ] Conflict-of-interest check completed

## 5. Engagement setup

- [ ] Engagement letter / MSA signed
- [ ] NDA in place
- [ ] Associates identified, contracted (back-to-back terms), and briefed
- [ ] Client workspace created; document control and version control configured
- [ ] Programme plan instantiated from the AOC project-plan template
- [ ] Kickoff scheduled; RACI and weekly cadence confirmed

## 6. Handover to delivery

- [ ] Programme lead assigned
- [ ] Authority liaison contact confirmed
- [ ] Findings/action register and risks/assumptions log opened
- [ ] Tier 3 retained-compliance conversation flagged for handover stage
