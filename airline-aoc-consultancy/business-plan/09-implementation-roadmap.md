# 09 — Implementation Roadmap (0–18 months)

A founder-led launch. The sequence is designed so that **credibility and the
first anchor client come before any significant fixed cost**.

## Phase 0 — Foundations (Month 0–2)

- [ ] Confirm the founder's positioning, track record, and authority
      relationships (the whole plan rests on this).
- [ ] Incorporate; choose the corporate structure with an accountant/lawyer.
- [ ] Bind **Professional Indemnity** and other insurance.
- [ ] Draft core legal templates: engagement letter/MSA, NDA, associate
      agreement.
- [ ] Decide the initial jurisdiction focus (UK-first, EASA-first, or dual).
- [ ] Register brand, domain, and basic online presence.

## Phase 1 — Build the product & the bench (Month 1–4)

- [ ] Build the **document factory v1** — master templates for OM A–D, SMS /
      Compliance Monitoring, MEL, training docs, and the compliance matrix.
- [ ] Productise the three tiers with scope, deliverables, and a rate card.
- [ ] Recruit and vet the **first associates** (ops, airworthiness/CAMO
      partner, training specialist).
- [ ] Stand up tooling: document management, CRM, knowledge base.
- [ ] Produce the methodology one-pager and first thought-leadership pieces.

## Phase 2 — First revenue (Month 3–8)

- [ ] Activate the founder network; secure **first Tier 1 feasibility** clients.
- [ ] Build the partner referral network (law firms, lessors, CAMOs, OEMs).
- [ ] Win the **first Tier 2 anchor certification programme**.
- [ ] Run the anchor programme flawlessly — this is the reference that unlocks
      everything else.
- [ ] Capture lessons into the template library and findings playbook.

## Phase 3 — Prove the model (Month 6–12)

- [ ] Convert the anchor client into the **first Tier 3 retained** engagement at
      handover.
- [ ] Hire the **second senior consultant** to reduce key-person risk.
- [ ] Publish the first anonymised **case study** and secure references.
- [ ] Deepen the associate bench with specialist/approval capability.
- [ ] Establish the regulatory-monitoring cadence and client update briefings.

## Phase 4 — Scale (Month 12–18)

- [ ] Run **multiple concurrent programmes** using the coordinator role and the
      bench.
- [ ] Grow the **recurring retained book** toward covering fixed overhead.
- [ ] Add specialist modules (PBN, LVO, ETOPS/EDTO, HEMS/offshore) and the
      **dual UK+EASA** programme as a headline offer.
- [ ] Formalise the internal quality-management / self-audit loop (Section 8).
- [ ] Review pricing and margins against actuals; refine the financial model.

## Critical success factors

1. **Founder credibility** — nothing sells without it.
2. **A flawless first programme** — the reference that compounds.
3. **Recurring revenue discipline** — Tier 3 covering overhead removes the
   feast-or-famine trap.
4. **The document factory** — the efficiency and margin engine; protect and
   improve it every engagement.
5. **Reputation, always** — the asset that takes years to build and one bad job
   to lose.
